# lab7-Machine-learning
Суммаризация абстрактов медицинских статей с BART, перевод на русский язык, тематическое моделирование (LDA) и кластеризация документов на основе тематических профилей. Реализованы классы для загрузки данных, суммаризации, перевода, тематического моделирования и кластеризации. Оценка ROUGE и интерпретация кластеров.
