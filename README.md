# Лабораторная работа №7: Обработка текстов — суммаризация, перевод, тематическое моделирование и кластеризация

## Описание
В работе решается задача обработки текстов на примере абстрактов научных статей медицинской тематики. Выполнена суммаризация (сжатие) абстрактов до 3–4 предложений с использованием модели BART (facebook/bart-large-cnn). Полученные суммаризации переведены на русский язык с помощью модели машинного перевода (Helsinki-NLP/opus-mt-en-ru). Далее выполнено тематическое моделирование на русскоязычных суммаризациях с помощью LDA. Для дополнительного анализа документы кластеризованы на основе их тематических профилей (распределений по темам) с использованием KMeans; проведена интерпретация кластеров через доминирующие темы LDA. Весь пайплайн реализован в виде отдельных классов для каждого этапа.

## Технологии
- **Python 3.7+**
- **pandas, numpy** – обработка данных
- **transformers, torch** – суммаризация и машинный перевод (BART, OPUS-MT)
- **nltk, pymorphy3, gensim** – предобработка текста, лемматизация, тематическое моделирование (LDA)
- **scikit-learn** – кластеризация (KMeans), метрики (силуэт, Calinski-Harabasz, Davies-Bouldin), t-SNE визуализация
- **rouge-score, bert-score** – оценка качества суммаризации
- **matplotlib, seaborn** – визуализация

## Функциональность

### 1. Загрузка данных
- Класс `DataLoader` загружает данные из Excel-файла, извлекает колонку `Abstract` и возвращает список абстрактов.
- Для ускорения эксперимента используется подвыборка из 500 документов (из 1500).

### 2. Суммаризация (на английском)
- Класс `Summarizer` загружает предобученную модель `facebook/bart-large-cnn`.
- Выполняет батчевую суммаризацию с заданными параметрами (max_length=150, min_length=50, num_beams=4).
- Оценивает качество суммаризации с помощью метрик ROUGE-1, ROUGE-2, ROUGE-L.

### 3. Перевод на русский язык
- Класс `Translator` использует модель `Helsinki-NLP/opus-mt-en-ru` для перевода суммаризированных текстов.
- Перевод выполняется батчами (batch_size=8) для ускорения.

### 4. Тематическое моделирование
- Класс `TopicModeler`:
  - Предобрабатывает русские тексты: приведение к нижнему регистру, удаление пунктуации, токенизация, лемматизация (pymorphy3), удаление стоп-слов (стандартные русские стоп-слова + расширенный список).
  - Строит словарь и корпус для LDA.
  - Подбирает оптимальное число тем по когерентности (coherence score) в диапазоне 3–7.
  - Обучает LDA-модель с выбранным числом тем.
  - Выводит ключевые слова для каждой темы.
  - Для каждого документа вычисляет вектор распределения по темам.

### 5. Кластеризация
- Класс `DocumentClusterer`:
  - Масштабирует тематические векторы (StandardScaler).
  - Подбирает оптимальное число кластеров по силуэт-коэффициенту (диапазон 2–9).
  - Выполняет кластеризацию KMeans с оптимальным K.
  - Оценивает качество кластеризации: силуэт, Calinski-Harabasz, Davies-Bouldin.
- Функция `interpret_clusters` анализирует каждый кластер:
  - Определяет доминирующую тему LDA для документов в кластере.
  - Выводит примеры статей (заголовки и фрагменты суммаризаций) из каждого кластера.
- Визуализация: t-SNE проекция тематических векторов с цветовой маркировкой кластеров.

## Результаты

### Качество суммаризации (ROUGE, усреднённые по 500 документам)
- ROUGE-1: Precision 0.9873, Recall 0.3186, F1 0.4459
- ROUGE-2: Precision 0.9453, Recall 0.3036, F1 0.4245
- ROUGE-L: Precision 0.9750, Recall 0.3133, F1 0.4393

### Темы LDA (оптимальное число тем = 6)
Примеры тем и ключевых слов:
- Тема 0: модель, языковой, интеллект, искусственный, данные, технология, крупный, исследование
- Тема 1: языковой, модель, крупный, chatgpt, область, моделей, исследование, искусственный
- Тема 2: область, вопрос, млм, языковой, модель, моделей, крупный, решение
- Тема 3: чатгпт, вопрос, пациент, провести, связанный, инструмент, различный, оценка
- Тема 4: область, медицинский, интеллект, искусственный, млм, образование, пациент, чатгпт
- Тема 5: исследование, модель, вопрос, chatgpt, языковой, ответ, оценка, точность

### Кластеризация
- Оптимальное число кластеров по силуэту: 6 (при выборе оптимального автоматически) либо 9 (при ранжировании по силуэту).
- Полученные кластеры хорошо соответствуют доминирующим темам LDA, что подтверждает интерпретируемость группировки документов.
- Пример интерпретации кластера: Кластер с доминирующей темой «ChatGPT и большие языковые модели» содержит статьи, в которых обсуждаются возможности и ограничения ChatGPT в медицине.

### Визуализация
t-SNE проекция демонстрирует хорошее разделение кластеров, что подтверждает структуру данных.

## Выводы
- Модель суммаризации BART обеспечивает приемлемое сжатие текста, сохраняя ключевую информацию (ROUGE-L F1 ≈ 0.44).
- Машинный перевод на русский язык позволяет проводить дальнейший анализ на родном языке.
- LDA выделяет 6 содержательных тем, связанных с различными аспектами применения больших языковых моделей в медицине.
- Кластеризация на основе тематических профилей даёт интерпретируемые группы документов, что может быть полезно для автоматической категоризации научных работ.
- Полученный пайплайн (суммаризация → перевод → тематическое моделирование → кластеризация) может быть адаптирован для других коллекций текстов.
